## Project Overview

Amara & Co. is a fictional South African clothing retail business offering everyday clothing and accessories. The website was developed as a responsive five-page e-commerce-style website designed to provide customers with information about the organisation, its products, enquiry options and contact information.

The website consists of five main pages:

* Home
* About Us
* Shop
* Enquiry
* Contact

The website was developed using HTML5, CSS3 and JavaScript. Responsive web design techniques were implemented to ensure that the website adapts to desktop, tablet and mobile screen sizes.

---

The target audience consists of South African consumers interested in everyday clothing and accessories.

# Website Pages

## Home — `index.html`

The homepage introduces Amara & Co. and provides visitors with an overview of the organisation and navigation to the main areas of the website.

## About Us — `about.html`

The About Us page provides information about the organisation, including its background, mission, vision and values.

## Shop — `products.html`

The Shop page displays the available products.

### Womenswear

* Linen Wrap Dress
* Cotton Poplin Shirt
* Tailored Wide-Leg Trousers

### Menswear

* Everyday Crew Tee
* Cotton Overshirt
* Straight-Fit Chinos

### Accessories

* Canvas Tote Bag
* Woven Belt

The Shop page includes product search functionality, responsive product images and an interactive image lightbox.

## Enquiry — `enquiry.html`

The Enquiry page contains a form that allows visitors to submit product and service enquiries.

The form includes validation and provides a response after successful processing.

## Contact — `contact.html`

The Contact page provides contact information and an interactive map containing multiple locations.

It also includes a general contact form that allows visitors to submit messages.
